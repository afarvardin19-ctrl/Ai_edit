1) Python 3.11+ نصب کنید.
2) pip install -r requirements.txt
3) .env.example را به .env تغییر نام دهید و Bot Token جدید و Chat ID را وارد کنید.
4) رمز مدیریت را تغییر دهید.
5) python app.py
6) سایت: http://127.0.0.1:5000
7) پنل: http://127.0.0.1:5000/login

توکن قبلی که در چت منتشر شده را استفاده نکنید؛ از BotFather توکن جدید بگیرید.
برای ارسال خصوصی، ابتدا در ربات /start بزنید.
